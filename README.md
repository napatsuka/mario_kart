# にゃりおカート(スマホ向け試作版)

開発指示書(第2版)をもとにした、オリジナルIPのカートレーシングの試作版です。HTML5 + Three.js で作っており、iOS Safari と Android Chrome のブラウザで遊べます。素材ファイルは使っていません(モデルは図形の組み合わせ、BGM と効果音は WebAudio で合成)。

## 起動方法

**いちばん簡単: `index.html` をダブルクリック**(Chrome / Edge / Safari / Firefox)。
プログラムと画像を1つにまとめた単体版なので、サーバーは不要です。ただし three.js とフォントをインターネットから読むため、ネット接続が必要です。

開発するとき:
- ソースは `dev.html` と `js/`、`assets/` です。`index.html` は自動生成なので直接編集しないでください。
- 変更を確認するときはサーバーで `dev.html` を開きます。
  ```bash
  python .claude/serve.py 8766
  ```
  → http://localhost:8766/dev.html (スマホは同じ Wi-Fi で `http://<PCのIP>:8766/dev.html`)
- 変更したら単体版を作り直します。
  ```bash
  python tools/build_standalone.py
  ```
- PC での操作: ←→ / A D でハンドル、Space / Shift でドリフト、X / Z / Enter でアイテム。

## 第9弾の更新

- **スタート信号**: 赤ランプが残り3・2・1秒で1つずつ点き、全部緑でスタート。
- **ロケットスタート**: ドリフトボタンを押し始めたタイミングで判定(スタートまで押し続けること)。2つ目のランプ以降 → 大加速 / 1つ目のあと → 小加速 / 1つ目より前 → エンスト。押している間はエンジンをふかす音と煙。
- **コイン**: 各コース35枚(7か所×5枚、取ってから9秒で復活)。1枚ごとに最高速 +1%、上限10枚(+10%)。ぶつけられると3枚落とす。

## 第6弾の更新

- **音楽**: タイトル/メニューは「Grand Prix Start」、レース中は「Turbo Circuit」(`assets/audio/menu.mp3` / `race.mp3`)。最初のタップで再生開始。BGM音量の設定が効きます。
- **メニュー**: メインメニューのボタンがパネルの高さいっぱいに広がり、空きができないように。
- **立体コース**: 道に高低差(坂の頂上ではジャンプ)。地面のコースは道に沿った起伏の地形と盛り土、海・溶岩・宇宙・夜の街は柱で支える橋。トンネル(照明つき)、山道、氷山の海、溶岩の上の橋、宇宙の浮遊ロード。上り坂で減速・下り坂で加速、氷のコースは曲がりにくい。
- **逆転アイテム**: カミナリ(自分以外全員スピン+小さく)、ねこロケット(自動で猛スピード・無敵)、ビッグにゃん(巨大化・無敵)、トップねらい弾(1位を追って大爆発)、まっくろスミ(前の全員の視界を黒く)、おいかけ弾×3。スターもあり。下位ほど強いアイテムが出ます。

## 第5弾の更新

- **縦持ち対応**: 縦にしても一時停止せずにそのまま遊べる。縦用の配置(左下に◀▶、右下にドリフト、その上にアイテム、順位とラップは左上の2段、ミニマップは小さく)と、縦長に合わせて少し引いた広めのカメラ。キャラ選択の「決定」や設定画面の選択ボタンが重なる・折り返す問題も修正。
- **コースを複雑・高難度に**: 高い次数の波と座標のゆがみで、ヘアピン・S字・連続コーナーを作る。壁どうしが重ならないこと、曲がりきれる半径であることを自動検査して作り直す。カップが進むほど(どんぐり→ほしぞら→いなずま→おうかん)カーブがきつく長くなり、路上のタル(0/4/8/12個)が増える。コース幅は 16→14 に。
- CPU は前方のカーブの鋭さに合わせて減速し、タルを避ける。プレイヤーはハンドルを大きく切ると少し減速して小さく曲がれる(ヘアピン対策)。

## 第4弾の更新

- **キャラクター**: クロは「写真を貼った3D」。キャラクターシートの正面と横のシルエットから高さごとの断面を求めて立体を作り、正面・背面・横の写真をその立体に投影しています(`js/figure.js`、データ生成は `tools/build_figure.py`)。ほかの7体はネコ以外の動物(柴犬・ウサギ・パンダ・ペンギン・キツネ・カエル・タヌキ)で、同じ体型に手描きの顔とお腹を投影し、耳・しっぽ・目の出っ張りを3Dで付けています。
- **タイトル画面**: 晴れたコースでカートが手前に迫るカメラ、1文字ずつ色の違う立体ロゴ「にゃりお」+メッキ調の「カート」、紙吹雪、黄色の「タップしてスタート」。
- **メニュー画面**: 青い左パネルに丸いピル型ボタン(グランプリ/タイムアタック/VSレース/デイリー/キャラクター/オンライン)、右側の虹色アーチ越しにレースが見える構成。Ⓐけってい・Ⓑもどるのヒント付き。
- 背景のデモ走行は晴れたコース(草原・海辺)だけを使う。

3Dデータを作り直すとき:
```bash
python tools/build_figure.py tools/kuro_sheet.jpg assets/figure
```

## 実装済み(指示書との対応)

| 指示書 | 実装内容 |
|---|---|
| 3.1 走行・ドリフト | オートアクセル。操作方式はボタン/傾き/スティックの3種類。ボタンの大きさ・透明度を変更でき、左利き用の反転あり。ドリフトは3段階の火花とミニターボ。オートドリフト補助、ロケットスタート |
| 3.2 アイテム | 順位に応じた抽選で、下位ほど強力。ロケット、ロケット×3、おいかけ弾、うしろ爆弾、ゼリー(トラップ)、きらきらバリア(無敵)。長押しで後ろに構えてガードできる。被弾は振動・赤フラッシュ・字幕で伝える |
| 3.3 レースルール | 2周で約90秒。難易度3段階、スマートステア、CPUのラバーバンド |
| 4 モード | カップ戦(中断しても続きから再開可)、デイリーチャレンジ(連続日数を記録)、タイムアタック(ゴーストを保存)、非同期対戦(ゴーストを共有コードで送受信)、ガレージ |
| 5 コース | 12コース・6テーマ。シード値から自動生成し、自己交差しない。ダッシュパネルとアイテムボックスあり |
| 6 サウンド | コースごとの合成BGM、BGMと効果音の音量を個別設定。バックグラウンドへの移行や音声機器の変更時に自動で一時停止 |
| 7 技術 | 物理は60Hz固定(描画と独立)。30fps固定、または60fpsを選択可。動的解像度で処理落ち時に画質を下げる。電池残量20%以下では30fpsに制限。セーフエリア対応、縦持ちでは横向きを案内 |
| アクセシビリティ | 色覚サポート(火花の配色変更+文字表示)、振動のオン/オフ、字幕表示 |

## 未実装・要判断

- **指示書の食い違い**: 「12コース=3カップ×4コース」と「カップ戦=3コース約6分」は両立しないため、**4カップ×3コース**にしました。
- **オンライン対戦**: サーバー権威型の対戦サーバーが必要なため、画面は「準備中」としています。
- **クラウドセーブ(Apple/Google連携)、課金・広告、ストア申請**: 製品化の段階(Unity などへの移植時)で対応します。現在はブラウザの localStorage に保存しています。
- **Bluetoothコントローラー**: 指示書どおり、後から追加する任意機能として扱います(キーボードには対応済み)。
- 実機20機種での性能・発熱の検証と、初見プレイヤーでのテストは未実施です。

## ファイル構成

- `index.html`: 画面・HUD・タッチUIのスタイル
- `js/main.js`: メニュー、メインループ、中断と復帰、保存、結果画面
- `js/game.js`: レース本体(物理、AI、アイテム、順位、カメラ、ゴースト)
- `js/track.js`: コースの自動生成とメッシュ
- `js/kart.js`: カート・アイテムのモデル
- `js/figure.js`: 写真/手描きの顔を投影する3Dフィギュア
- `js/env.js`: 空・山・雲・ライト
- `js/particles.js`: パーティクル
- `js/showroom.js`: キャラ選択の展示台
- `js/input.js`: タッチ/傾き/スティック/キーボード入力
- `js/audio.js`: 合成BGM・効果音・エンジン音
- `js/data.js`: キャラ、コース、アイテム、抽選テーブル
- `js/storage.js`: 設定とセーブ、ゴースト共有コード
